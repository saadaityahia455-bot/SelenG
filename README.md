# 致贝贝 · 一封从深圳寄回去的回信

> 千里之外,你把一整个夏天的想念,都塞进了那个紫蓝色的小盒子。
> 现在,我把这份心意,一笔一笔,还给你。

这是一封**用代码写的情书** —— 一个纯静态网页,记录一对异地恋人在 2026 年夏天的小心意。
九件礼物、一封手写信、五百二十遍名字的彩蛋、一首钢琴曲,和一封认真写给她的回信。

这不是商业产品。这不是炫技 Demo。
**这是一个 18 岁男生,想用自己会的全部技术,把女朋友的礼物"做成"一份回信。**

## 🎯 项目特色

| 特性 | 说明 |
|------|------|
| **零依赖** | 纯原生 HTML/CSS/JS,无需 npm/yarn/webpack,无构建步骤 |
| **单页静态** | 3 个文件 (`index.html` + `style.css` + `script.js`) + 1 个图片文件夹 |

| **GitHub Pages 部署** | 一行命令就能上线 |

## 🚀 快速开始

### 方式 1 · 直接打开

下载整个项目,双击 `index.html`,用浏览器打开即可。
**(注意:Chrome 对本地 file:// 协议下图片加载有限制,推荐用方式 2)**

### 方式 2 · 本地服务器(推荐)

```bash
# 进入项目目录
cd love-letter

# Python 3
python -m http.server 8000

# 或者 Node.js
npx serve
```

浏览器打开 `http://localhost:8000`

### 方式 3 · 部署到 GitHub Pages

1. Fork 这个仓库
2. 在仓库设置 → Pages → 选择 `main` 分支
3. 等待 1-2 分钟,你的专属链接就会生成

## 💌 把它改成你自己的情书

**这是这个项目最有价值的部分 —— 不是看,而是用。**

如果你也想给某个重要的人写一封"代码情书",跟着改:

### 1. 准备照片

把你/对方的礼物照片拍下来,放到 `images/` 文件夹。
推荐文件名:

```
images/
├── letter.jpg      ← 对方写给你的手写信
├── gift-01.jpg     ← 第 1 件礼物
├── gift-02.jpg     ← 第 2 件礼物
├── ...
└── gift-09.jpg     ← 第 9 件礼物
```

### 2. 改 index.html

打开 `index.html`,找到下面这些位置替换成你自己的内容:

| 位置 | 改什么 |
|------|--------|
| `<title>` 标签 | 网页标题(浏览器标签显示) |
| `<div class="cover-from">` | 你的距离(山东 ➜ 深圳 · 1800 km) |
| `<h1 class="t-line">` | 收信人的名字(致 贝 贝) |
| `<p class="cover-quote">` | 你的开场白 |
| `<div class="cover-meta">` | 署名 + 学校 + 日期 |
| 9 个 `<article class="page">` | 每件礼物的图片、名字、文案 |
| `<section class="letter">` | 回信正文 |

### 3. 改背景音乐

在 `index.html` 找这段:

```html
<audio id="bgm" preload="auto" loop playsinline
       src="https://music.163.com/song/media/outer/url?id=1299980643.mp3"></audio>
```

替换 `src` 为你们的故事里的某首歌。

**几个推荐曲目:**
- *Kiss the Rain* — Yiruma(本项目默认)
- *River Flows in You* — Yiruma
- *Summer* — 久石让
- *Merry Christmas Mr. Lawrence* — 坂本龙一
- *那年夏天* — 赵英俊

或者用你们一起听过的某一首歌 —— 这才是杀伤力最大的。

### 4. 改名字

`script.js` 里这段:

```js
ctx.fillText('韩天宇 ♥', 0, 0);
```

把"韩天宇 ♥"换成收信人的名字。

### 5. 部署

- **GitHub Pages**(免费,推荐)
- **Vercel**(免费,速度快)
- **Netlify**(免费,带表单功能)
- **自己的服务器**(国内访问快)

## 🛠 技术栈

- **HTML5** — 语义化结构,无依赖
- **CSS3** — Grid 布局,`clamp()` 流式字号,`@media` 响应式,`backdrop-filter`
- **Vanilla JS** — `IntersectionObserver` 入场动画,`<canvas>` 名字雨,`<audio>` 背景音乐
- **零依赖** — 没有 npm package,没有 React/Vue/jQuery

**为什么不用框架?** —— 因为这是一封情书,不需要"工程化"。
打开 `index.html` 就能改每一句话,这比 `npm install` 后才能改更重要。

## 🎨 设计理念

### 1 · 视觉语言:手账纸

- **米黄纸色**(`#f5efe3`)代替纯白,呼应贝贝的手写信
- **楷体** 标题 (`Ma Shan Zheng`) — 不用黑体不用宋体,因为这是家书
- **朱砂红**(`#b14233`)点缀 — 印章、爱情、不能太工业
- **纸质噪点**叠层 — 整页像从笔记本撕下来的一页

### 2 · 动效语言:克制

- 入场用 `IntersectionObserver`,滚到才浮现,不打扰阅读
- 拍立得照片用 `mousemove` 轻微视差(桌面端)
- 名字雨用 `<canvas>` 而不是 DOM(避免布局抖动)
- 所有动画都尊重 `prefers-reduced-motion`

### 3 · 文字语言:克制

- 每件礼物只有 3 段话:**诗化的画面 / 描述 / 一句脚注**
- 不堆砌形容词,不说"你真美"这种空话
- 把礼物背后的**细节**写出来 —— "你说不要嫌弃我的字",比"你的字真可爱"动人

## 🎁 彩蛋 & 隐藏功能

| 操作 | 效果 |
|------|------|
| 首次点击页面任意位置 | 背景音乐自动开始播放 |

| 在第 3 页(礼物页)点"点我看辣条全貌" | 全屏灯箱放大 |
| 滚到 520 高潮页 | 名字雨 canvas 启动 |
